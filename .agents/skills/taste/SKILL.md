# Taste: Anti-Slop Frontend Design Skill

This skill is the direct alias for the full **taste-skill** ([design-taste-frontend](../design-taste-frontend/SKILL.md)).

## Quick Start & Core Directives

1. **Brief Inference First:** Before writing code, infer the project's visual soul. Don't default to generic AI tropes (purple gradients, standard bento grids, 3 equal cards, floaty glow spheres).
2. **Set The Three Dials:**
   - **`DESIGN_VARIANCE` (1-10):** How much visual surprise, asymmetry, and layout variation (default: 8).
   - **`MOTION_INTENSITY` (1-10):** Speed, springiness, and presence of micro-interactions (default: 6).
   - **`VISUAL_DENSITY` (1-10):** Information density from sparse art gallery to dense trading terminal (default: 4).
3. **Typography & Layout Cadence:** Use purposeful font pairings, asymmetric balance, generous section whitespace, and intentional contrast.
4. **Anti-Default Discipline:** Eliminate boilerplate patterns. Every component must feel bespoke to the client's brand.

For the exhaustive guide, dial matrices, and design system templates, refer to [design-taste-frontend](../design-taste-frontend/SKILL.md).
